# DungeonsAndStudents — консольная RPG

Учебная консольная игра на Java: персонаж исследует подземелье, получает снаряжение и пытается выбраться.

## Возможности

- создание персонажа с именем игрока;
- случайная генерация оружия и элементов брони с разными характеристиками и редкостью;
- инвентарь, характеристики персонажа и расчёт шанса выживания;
- случайные встречи с противниками;
- получение новой экипировки после победы и попытка выбраться из игрового мира.

## Технологии

- Java 14 или новее;
- объектно-ориентированный подход: классы игрока и инвентаря, абстрактные классы `Armor` и `Weapon`, интерфейс игровых действий;
- стандартная библиотека Java.

## Запуск

Открой проект в IntelliJ IDEA и запусти класс `DungeonsAndStudents.Main`. Сохрани все исходные файлы в каталоге `src/DungeonsAndStudents/`.
